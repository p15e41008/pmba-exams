# PM 學程考古題刷題系統

台大 PMBA 必修課考古題的線上刷題與錯題複習系統，目前收錄財務管理與行銷管理兩科。

進站需要輸入班上的共用密碼。這是一道**門簾，不是鎖**：站台是公開 repo 上的靜態頁面，
密碼必然寫在原始碼裡，作用是不讓班外的人隨手逛進來、不被搜尋引擎收錄，擋不住有心人。
理由與被否決的替代方案見 `docs/adr/0001-static-password-is-a-curtain-not-a-lock.md`。
因此這個 repo 不放任何真正需要保密的東西。

* 🌐 **正式線上網址**：[https://p15e41008.github.io/pmba-exams/](https://p15e41008.github.io/pmba-exams/)

## 一、同學使用說明（免安裝、零門檻）

其他同學使用時**無需下載任何檔案或手動設定**：
1. 直接在手機或電腦瀏覽器點開線上網址：[https://p15e41008.github.io/pmba-exams/](https://p15e41008.github.io/pmba-exams/)
2. 第一次進站輸入班上的共用密碼，之後同一支手機／同一個瀏覽器就不會再問（清掉瀏覽器資料或換裝置才需要重新輸入）。
3. 系統會**自動下載同目錄的各科題庫 Excel**（財務管理 514 題、行銷管理 640 題），並快取至設備本機儲存區（LocalStorage）。
4. 左上角可切換科目；切換後，試卷／章節／主題三個篩選器只會列出該科的選項。
5. 支援依照試卷、章節、核心主題、高頻考題次數與關鍵字進行多維度篩選。
6. 提供「排除重複題目」、「只顯示需複習」、「只顯示尚未作答」開關。
7. 支援手機單手刷題、即時 O/X 答題回饋、詳盡解析展開與點擊放大圖表。

## 二、維護說明

### 更新既有科目的題庫（題庫維護者自己來，不需要動程式）

在 GitHub 網頁版把新的 Excel 上傳到 repo 根目錄，覆蓋同名檔案即可。
GitHub Pages 會自動重新發佈，同學下次開站就會拿到新版，他們不需要做任何事
（網站每次開站都會在背景重抓官方題庫，不吃瀏覽器快取）。

**唯一的例外**：曾經按過「匯入 Excel 題庫」的同學，他的瀏覽器從此停用自動同步，
以免手動匯入的題庫被官方版本蓋掉。這種情況要按一次右上角的「重新整理題庫」才會回到
官方題庫並恢復自動同步。驗收時請注意：如果你自己也匯入過，你看到的題數不會變，
那是假綠燈——先按「重新整理題庫」再看。

三個必須遵守的地方：

1. **檔名要一模一樣**，包含中文字與副檔名。上傳成 `行銷管理考古題(1).xlsx` 這種
   自動加編號的檔名時，舊檔還在、新檔不會被讀到——網站看起來一切正常，其實沒更新。
   這是最常見也最難發現的錯誤。
2. **只碰 `.xlsx`**。欄位標題不要改、不要刪、不要加空白；九個欄位名必須完全一致：
   課程／考古題／#／答案／題目／補充說明／出現次數／對應講義章節／核心主題。
   標題對不上、或檔案本身壞掉時，那一科會整個讀不進來：它會暫時從科目切換器消失，
   標題下方的狀態列顯示「<科目>讀取失敗」，其他科照常運作。
3. **上傳完自己開一次網站，看標題下方的題數有沒有變**。這一步能抓到上面兩種錯誤的絕大多數。

新增一批題目時，在「考古題」欄自己標一個可辨識的批次名（例如 `2026/期中考猜題_第一組`），
同學就能在篩選器裡認出這批是哪次考試、誰整理的。不需要為此新增科目或新增檔案。

### 新增一個科目（要改一行程式）

1. 把該科的 `<科目名>考古題.xlsx` 放進本目錄（欄位沿用現有格式：課程／考古題／#／答案／題目／補充說明／出現次數／對應講義章節／核心主題）。
2. 在 `index.html` 的 `EXCEL_SOURCES` 加一行。
3. 畫面左上角的科目切換器會自己長出新科目，不需要改其他地方。

### 更換共用密碼

改 `index.html` 裡的 `GATE_PASSWORD` 一行後 commit。改完之後，已經進過站的同學不受影響
（他們的瀏覽器記著「已通過」而不是密碼本身），只有新裝置需要用新密碼。

### 歷史版本

`_archive/` 存放單科時代的 v1～v6 完整快照。底線開頭的目錄不會被 GitHub Pages 發佈，
所以它們不會成為繞過門簾的後門。

## 三、開發者測試指引 (Testing Guide)

在修改程式碼且尚未 Push 上線前，若要在本機進行端對端（E2E）測試，請依下列方式進行：

### 1. 電腦瀏覽器模擬手機版（最推薦、3 秒完成）

模擬「全新手機、第一次使用、無任何快取」的最快方式：

1. **啟動本機伺服器**：
   * 在專案目錄按兩下執行 `start-e2e-test.bat`，或在終端執行：
     ```bash
     python -m http.server 8080
     ```
2. **開啟無痕式視窗**：
   * 在 Chrome 或 Edge 瀏覽器按 `Ctrl + Shift + N` 開啟無痕視窗（確保 LocalStorage 完全空白乾淨）。
   * 網址輸入：`http://localhost:8080/`
3. **切換手機模擬模式**：
   * 按下鍵盤 **`F12`** 打開開發者工具。
   * 按下快速鍵 **`Ctrl + Shift + M`** 切換為行動裝置模式（Device Toolbar）。
   * 在上方裝置下拉選單切換至 **iPhone 14 Pro** 或 **Samsung Galaxy S20**（寬度約 360~393px）。
4. **檢查重點**：
   * 門簾是否出現、輸入共用密碼後是否進得去、重整後是否不再詢問。
   * 題庫是否自動讀取成功（兩科共 1154 題），左上角科目切換器是否兩科都在。
   * 題目清單上方「開始練習 Selected (512)」大按鈕是否清楚可見。
   * 畫面滾動時，最下方是否常駐吸底的綠色「開始練習」懸浮條。
   * 篩選器開關文字是否排版整齊、無折斷重疊。

### 2. 手機端 Wi-Fi 真實連線測試

1. 確認手機與電腦連接在**同一個 Wi-Fi 區域網路**。
2. 雙擊 `start-e2e-test.bat`，視窗會自動偵測並顯示您電腦的區網 IP。
3. 手機開啟 Safari / Chrome 瀏覽器，輸入該網址（例如 `http://192.168.1.76:8080/`）即可實機操作測試。

  * **單科時代的「課程名稱」篩選器移除**：科目切換器取代它，同一件事不放兩個控制項。
  * **單科讀取失敗不再拖垮全站**：某一科的 Excel 讀不到時，其他科照常使用，狀態列標示是哪一科失敗。
  * **歷史版本快照移入 `_archive/`**：留在 repo 但不發佈上線，避免成為門簾的後門。
* **v6 (2026/09/03 - UX 體驗飛躍版：隨機抽題設定 ＋ 告別 67% 縮放滾動 ＋ 小鍵盤盲打流 ＋ 測驗結算成績單)**：
  * **快速練習設定彈窗 (Setup Modal)**：點擊「開始練習」時跳出模式選單，支援「🔀 隨機亂序抽題（Fisher-Yates 洗牌不重複）」與「▶ 順序練習」，並提供 10 題、20 題、50 題或自訂題數的抽樣模擬考。
  * **告別 67% 瀏覽器縮放與視窗滾動（就近內聯操作）**：收斂卡片空白與高度預算；作答後，高亮「下一題 ▶」快捷按鈕原地緊鄰浮現，滑鼠移動不到 30px 即跳下一題，100% 縮放下無需滾輪滾動視窗。
  * **電腦版小鍵盤單手盲打速刷流（Numpad & Standard Keyboard）**：
    * `1` / `Numpad 1`：作答 **O（正確）**
    * `2` / `Numpad 2`：作答 **X（錯誤）**
    * `3` / `Numpad 3`：展開 / 收合解析
