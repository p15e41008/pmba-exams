# 靜態密碼是門簾，不是鎖

網站放在公開 repo 的 GitHub Pages 上，沒有伺服器，所以任何密碼都必然躺在使用者拿得到的檔案裡。我們仍然加了一道共用密碼的門簾，目的是「讓班外的人不要隨手逛進來、不要被搜尋引擎收錄」，而不是防止有心人取得內容——後者在這個架構下做不到。

**Status**: accepted

## Considered Options

- **整站加密（staticrypt 式）**：內容真的變成亂碼，但每次更新題庫都要多一道加密步驟，而現行「把新的 Excel 丟進 repo 就完成更新」是每週會做的事；也會連帶影響「重新整理題庫／匯入 Excel」兩個既有功能。代價落在最高頻的動作上，否決。
- **repo 轉 private ＋ 外部存取控制**：能做到真正的身份驗證，但離開免費且零維運的 GitHub Pages 路線，且 private repo 發佈 Pages 需付費方案。對「同學之間分享練習題」這個用途過重，否決。

## Consequences

- 密碼以明文寫在 `index.html` 裡，這是**刻意**的，不是疏漏。未來讀到這段程式碼的人不需要「修好它」。
- 題庫 Excel 仍可由公開網址直接下載，門簾擋不到它。這同樣是已知且接受的。
- 因此這個 repo 不得放入任何真正需要保密的東西（個人資料、學校內部文件、付費教材）。判準：如果某份檔案外流會造成實際損害，它就不該進這個 repo。
